# File Handling in Python

## Introduction
File Handling allows Python programs to create, read, write, update, and manage files stored on a system.

Files are essential for:
- Saving user data
- Logs
- Reports
- Configuration
- CSV/JSON processing

---

# Why File Handling is Important
File Handling helps:
- Store permanent data
- Process external files
- Automate tasks
- Manage logs
- Build real-world applications

---

```python
file = open("data.txt", "r")
```

# Reading a File

```python
file = open("data.txt", "r")
print(file.read())
```

---

# Read Line

```python
print(file.readline())
```

---

# Read All Lines

```python
print(file.readlines())
```

---

# Writing to a File

```python
file = open("data.txt", "w")
file.write("Hello Python")
```

---

# Appending to a File

```python
file = open("data.txt", "a")
file.write("New Line")
```

---

# Closing a File

```python
file.close()
```

---

# Best Practice: with Statement

```python
with open("data.txt", "r") as file:
    print(file.read())
```

---

# File Existence Check

```python
import os

if os.path.exists("data.txt"):
    print("Exists")
```

---

# Delete File

```python
os.remove("data.txt")
```
