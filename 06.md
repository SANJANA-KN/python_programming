# Functions in Python

## Introduction
Functions are reusable blocks of code designed to perform specific tasks.

They help:
- Reduce repetition
- Organize code
- Improve readability
- Simplify debugging
- Build modular applications

Examples:
- Calculate totals  
- Validate login  
- Convert temperatures  
- Process data  

---

# Why Functions are Important
Functions help:
- Reuse code
- Improve structure
- Break large problems into smaller parts
- Increase maintainability
- Improve scalability

---

# Defining a Function

```python
def greet():
    print("Hello, Python!")
```

---

# Calling a Function

```python
greet()
```

---

# Output:
```python
Hello, Python!
```

---

# Function with Parameters

```python
def greet_user(name):
    print("Hello,", name)
```

---

# Example:
```python
greet_user("John")
```

---

# Return Statement

```python
def add(a, b):
    return a + b
```

---

# Example:
```python
result = add(10, 5)
print(result)
```

---

# Default Parameters

```python
def country(name="India"):
    print(name)
```

---

# Keyword Arguments

```python
def student(name, age):
    print(name, age)

student(age=20, name="Ravi")
```

---

# Arbitrary Arguments (*args)

```python
def total(*numbers):
    print(sum(numbers))
```

---

# Arbitrary Keyword Arguments (**kwargs)

```python
def profile(**data):
    print(data)
```

---

# Scope of Variables

## Local Scope:
```python
def test():
    x = 10
```

---

## Global Scope:
```python
x = 100
```

---

# Recursion
Function calling itself.

```python
def countdown(n):
    if n == 0:
        return
    print(n)
    countdown(n-1)
```

---

# Lambda Functions

```python
square = lambda x: x * x
```
