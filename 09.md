# Modules and Packages in Python

## Introduction
Modules and Packages help organize Python code into reusable files and folders.

---

# Module
A Python file containing functions or variables.

Example:
```python
math
random
```

---

# Importing Modules

```python
import math
print(math.sqrt(25))
```

---

# Import Specific Function

```python
from math import sqrt
```

---

# Alias

```python
import numpy as np
```

---

# Custom Module

## File:
```python
my_module.py
```

```python
def greet():
    print("Hello")
```

---

# Using Custom Module

```python
import my_module
my_module.greet()
```

---

# Package
A folder containing multiple modules.

---

# __init__.py
Marks package folder.

---

# pip
Python package installer.

```python
pip install requests
```

---

# Virtual Environment

```python
python -m venv env
```

---

# Benefits
- Reusability
- Organization
- Scalability

# Common Mistakes
- Wrong import path
- Missing installation
- Name conflicts

# Best Practices
- Use virtual env
- Organize logically
- Avoid wildcard imports
