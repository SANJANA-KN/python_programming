# Object-Oriented Programming in Python

## Introduction
Object-Oriented Programming (OOP) is a programming paradigm based on objects and classes.

---

# Why OOP is Important
OOP helps:
- Organize code
- Improve reusability
- Model real-world systems
- Scale applications
- Enhance maintainability

---

# Class
Blueprint for objects.

```python
class Student:
    pass
```

---

# Object

```python
s1 = Student()
```

---

# Constructor

```python
class Student:
    def __init__(self, name):
        self.name = name
```

---

# Instance Variable

```python
self.name
```

---

# Methods

```python
def greet(self):
    print("Hello")
```

---

# Example:

```python
class Student:
    def __init__(self, name):
        self.name = name

    def greet(self):
        print("Hello", self.name)
```
