# APIs and JSON in Python

## Introduction
APIs (Application Programming Interfaces) allow Python applications to communicate with external systems and services.

JSON (JavaScript Object Notation) is the most common format used to exchange data between applications.

Examples:
- Weather apps
- Payment gateways
- Login systems
- Social media integrations

---

# Why APIs and JSON are Important
They help:
- Fetch live data
- Connect applications
- Automate services
- Build web apps
- Process external systems

# Making a GET Request

```python
import requests

response = requests.get("https://api.example.com/data")
print(response.status_code)
```

---

# JSON Response

```python
data = response.json()
print(data)
```

---

# Access JSON Data

```python
print(data["name"])
```

---

# POST Request

```python
payload = {"name": "John"}

response = requests.post("https://api.example.com/users", json=payload)
```

---

# Common HTTP Methods

---

# Status Codes
- 200 → Success
- 201 → Created
- 400 → Bad Request
- 401 → Unauthorized
- 404 → Not Found
- 500 → Server Error

---

# Working with JSON

## Python Dictionary to JSON
```python
import json

data = {"name": "John"}
json_data = json.dumps(data)
```

---

## JSON to Dictionary
```python
python_data = json.loads(json_data)
```

---

# Error Handling

```python
try:
    response = requests.get(url)
    response.raise_for_status()
except requests.exceptions.RequestException:
    print("API Error")
```
