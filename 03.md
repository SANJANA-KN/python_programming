# Operators in Python

## Introduction
Operators are symbols used to perform operations on variables and values.

---

# Types of Operators
- Arithmetic
- Comparison
- Logical
- Assignment
- Bitwise
- Membership
- Identity

---

# Arithmetic Operators

```python
a = 10
b = 3
```

Addition:
```python
a + b
```

Subtraction:
```python
a - b
```

Multiplication:
```python
a * b
```

Division:
```python
a / b
```

Floor Division:
```python
a // b
```

Modulus:
```python
a % b
```

Exponent:
```python
a ** b
```

---
