# Loops in Python

## Introduction
Loops are used to repeat code multiple times efficiently.

---

# Types of Loops
- for loop
- while loop

---

# for Loop

```python
for i in range(5):
    print(i)
```

---

# while Loop

```python
x = 1

while x <= 5:
    print(x)
    x += 1
```

---

# break

```python
for i in range(5):
    if i == 3:
        break
```

---

# continue

```python
for i in range(5):
    if i == 2:
        continue
```

# Nested Loops

```python
for i in range(3):
    for j in range(2):
        print(i, j)
```

---

# Loop with else

```python
for i in range(3):
    print(i)
else:
    print("Done")
```

---

# Infinite Loop Warning

```python
while True:
    break
```

---

# Common Mistakes
- Infinite loops
- Wrong range
- Missing increment

---

# Best Practices
- Use for when count known
- Use while for conditions
- Avoid deep nesting
