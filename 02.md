# Variables and Data Types in Python

## Introduction
Variables in Python are used to store data values.

Python is dynamically typed, meaning you do not need to declare the type manually.

Examples:
- Store a name
- Store age
- Store salary
- Store login status

---

# Why Variables are Important
Variables help:
- Store data
- Reuse values
- Build logic
- Process user input
- Create scalable programs

---

# Creating Variables

```python
name = "John"
age = 25
salary = 50000.50
is_active = True
```

---

# Variable Naming Rules
- Must start with letter or _
- Cannot start with number
- Case-sensitive
- No spaces

Correct:
```python
student_name = "Ravi"
```

Wrong:
```python
2name = "Ravi"
```

---

# Multiple Assignment

```python
x, y, z = 10, 20, 30
```

---

# Common Data Types

## int
```python
age = 25
```

## float
```python
price = 99.99
```

## str
```python
name = "Python"
```

## bool
```python
is_logged_in = True
```

## complex
```python
x = 2 + 3j
```

---

# Type Checking

```python
print(type(age))
```

---

# Type Conversion

## int to float
```python
x = float(10)
```

## float to int
```python
y = int(5.8)
```

## int to string
```python
z = str(100)
```

---

# User Input

```python
name = input("Enter your name: ")
age = int(input("Enter age: "))
```

---

# Memory Concept
Variables reference objects in memory.

---

# Dynamic Typing

```python
x = 10
x = "Python"
```

---

# Constants
Python has no true constants, but uppercase is convention:

```python
PI = 3.14
```

---

# Common Mistakes

## Mistake 1:
Using wrong type:
```python
age = "25"
```

---

## Mistake 2:
Forgetting conversion:
```python
age = input()
```

---

# Best Practices
- Use meaningful names
- Follow snake_case
- Convert inputs properly
- Avoid unnecessary reassignment
