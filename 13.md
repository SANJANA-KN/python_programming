# SQL with Python

## Introduction
Python can connect with databases to perform CRUD operations and manage data programmatically.

---

# Why SQL with Python is Important
It helps:
- Build dynamic apps
- Manage databases
- Automate records
- Create backend systems

---

# SQLite Connection

```python
import sqlite3

conn = sqlite3.connect("students.db")
cursor = conn.cursor()
```

---

# Create Table

```python
cursor.execute("""
CREATE TABLE students(
    id INTEGER PRIMARY KEY,
    name TEXT,
    age INTEGER
)
""")
```

---

# Insert Data

```python
cursor.execute("INSERT INTO students (name, age) VALUES (?, ?)", ("John", 20))
```

---

# Read Data

```python
cursor.execute("SELECT * FROM students")
print(cursor.fetchall())
```

---

# Update Data

```python
cursor.execute("UPDATE students SET age = 21 WHERE name = 'John'")
```

---

# Delete Data

```python
cursor.execute("DELETE FROM students WHERE name = 'John'")
```

---

# Commit Changes

```python
conn.commit()
```

---

# Close Connection

```python
conn.close()
```

---

# SQL Injection Prevention
