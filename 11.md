# Exception Handling in Python

## Introduction
Exceptions are runtime errors that interrupt program execution.

Exception Handling prevents crashes and allows graceful error management.

---

# Why Exception Handling is Important
It helps:
- Prevent crashes
- Improve reliability
- Handle user errors
- Secure applications
- Improve debugging

---

# Basic try-except

```python
try:
    x = 10 / 0
except:
    print("Error occurred")
```

---

# Specific Exception

```python
try:
    num = int("abc")
except ValueError:
    print("Invalid number")
```

---

# Multiple Exceptions

```python
try:
    pass
except ValueError:
    pass
except ZeroDivisionError:
    pass
```

---

# else Block

```python
try:
    print("Safe")
except:
    print("Error")
else:
    print("No error")
```

---

# finally Block

```python
try:
    pass
finally:
    print("Always executes")
```

---

# Raising Exceptions

```python
raise ValueError("Invalid age")
```

---

# Custom Exception

```python
class CustomError(Exception):
    pass
```
