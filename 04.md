# Control Flow in Python

## Introduction
Control Flow determines how code executes based on conditions.

---

# Why Control Flow is Important
Control flow helps:
- Make decisions
- Execute selectively
- Build intelligent applications

---

# if Statement

```python
age = 18

if age >= 18:
    print("Eligible")
```

---

# if else

```python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

---

# if elif else

```python
marks = 85

if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
else:
    print("C")
```

---

# Nested if

```python
if age >= 18:
    if age >= 60:
        print("Senior")
```

---

# Short-Hand if

```python
print("Yes") if age >= 18 else print("No")
```

---

# Match Case (Python 3.10+)

```python
day = 1

match day:
    case 1:
        print("Monday")
```

---

# Common Mistakes
- Indentation errors
- Wrong condition order
- Missing colon

---

# Best Practices
- Keep conditions simple
- Use elif properly
- Avoid deep nesting
