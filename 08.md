# Strings in Python

## Introduction
A String is a sequence of characters used to store text.

Examples:
- Names
- Emails
- Passwords
- Messages

---

# Creating Strings

```python
name = "Python"
message = 'Hello'
```

---

# Multi-Line Strings

```python
text = """Python
is
awesome"""
```

---

# String Indexing

```python
name[0]
```

---

# String Slicing

```python
name[0:3]
```

---

# Common Methods
```python
upper()
lower()
strip()
replace()
split()
find()
```

---

# Example:
```python
text = "python"
print(text.upper())
```

---

# String Concatenation

```python
first = "Hello"
second = "World"

print(first + " " + second)
```

---

# f-Strings

```python
name = "John"
print(f"Hello {name}")
```

---

# Escape Characters
```python
\n
\t
\"
```

---

# Membership
```python
"a" in "apple"
```

---

# String Formatting
```python
"My age is {}".format(25)
```

---

# Common Mistakes
- Index out of range
- Wrong slicing
- Forgetting immutability

# Best Practices
- Use f-strings

- Validate strings
