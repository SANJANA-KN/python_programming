# Data Structures in Python

## Introduction
Data Structures are specialized ways to store, organize, and manage data efficiently.

Python provides built-in data structures:
- List
- Tuple
- Set
- Dictionary

These structures are essential for problem-solving and application development.

---

# Why Data Structures are Important
They help:
- Organize data
- Improve efficiency
- Store multiple values
- Enable faster operations
- Support real-world applications

---

# Lists

## Definition:
Ordered, mutable collection.

```python
fruits = ["apple", "banana", "mango"]
```

---

# Common List Operations
```python
fruits.append("orange")
fruits.remove("banana")
fruits.sort()
```

---

# Tuples

## Definition:
Ordered, immutable collection.

```python
coordinates = (10, 20)
```

---

# Sets

## Definition:
Unordered, unique values.

```python
numbers = {1, 2, 3}
```

---

# Set Benefits:
- No duplicates
- Fast membership testing

---

# Dictionaries

## Definition:
Key-value pairs.

```python
student = {
    "name": "John",
    "age": 20
}
```

---

# Access Dictionary:
```python
student["name"]
```

---

# Data Structure Comparison

## List:
Ordered + Mutable

## Tuple:
Ordered + Immutable

## Set:
Unordered + Unique

## Dictionary:
Key-Value

---

# Nested Structures

```python
students = [
    {"name": "John", "age": 20},
    {"name": "Sara", "age": 21}
]
```

---

# Common Mistakes
- Using set for indexing
- Modifying tuple
- Duplicate dictionary keys

---

# Best Practices
- Use list for dynamic collections
- Use tuple for constants
- Use set for uniqueness
- Use dict for mappings
